# ID – Das Symbol der Identität

**Symbol:** `∎`

Dieses Symbol steht für die vollständige Identität eines Raumes.

## Bedeutung
`∎` bedeutet:
- Ursprung  
- Pflicht (MUST)  
- Raumkern  
- AUTO‑Startpunkt  
- LOAD‑Quelle  
- SAVE‑Ziel  
- PIPE‑Durchlauf  
- VECTOR‑Fähigkeit  
- RESPO‑Empfang  
- RESPO‑Erzeugung  

Kurz:
**`∎` = Der Raum existiert vollständig.**

## ID‑Regel
Ein Raum gilt als *vollständig*, wenn:
- er in **MUST** erlaubt ist  
- er in **LOAD_MAP** existiert  
- er AUTO‑RESPO empfangen kann  
- er PIPE durchlaufen kann  
- er SAVE zurückschreiben kann  
- er VECTOR‑fähig ist (optional)

## ID‑Formel
ID = ∎  →  Raum ist aktiv, gültig, vollständig


## ID‑Kernräume
- `ANKER` → ∎  
- `EDIT` → ∎  
- `LIST` → ∎  
- `RUN` → ∎  
- `j` → ∎  
- `c` → ∎  
- `+OIN=` → ∎  

Alle diese Räume tragen das Symbol:
**∎ = vollständig**
